# Pokémon Explorer Application

A React-based web application that allows users to browse, search, and compare Pokémon. The app fetches Pokémon data from the PokéAPI and displays detailed information like stats, abilities, and moves. Users can select two Pokémon to compare their stats side by side or let the app randomly choose Pokémon for comparison.

## Features

- Search and filter Pokémon.
- View detailed Pokémon information (stats, abilities, moves).
- Compare two Pokémon’s stats.
- Random Pokémon comparison

## Tech Stack

- **React**
- **React Router**
- **PokéAPI**
- **TailwindCSS**

## Installation

### Prerequisites

- Node.js

### Setup

**Clone the repository**:

   ```bash
   git clone https://github.com/AnuragSingh012/Pokemon.git
   cd Pokemon
   ```

**Install dependencies and run the project**

```bash
npm install && npm run dev
```
